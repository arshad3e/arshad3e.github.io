A401106approved · Nov 2026

Ways to split 2n into two odd-composite-times-power-of-two parts

Published data stopped at n = 32. I extended it eight places, to n = 40, with a segmented odd-only sieve in C that pairs each number with its mirror 2n − c. A second, independent Goldbach-pair program agrees on n = 33–35.

A401384approved · Nov 2026

First n where σ(n) has exactly k new prime factors

σ(n) is the sum of n's divisors. The record for k = 10 was unknown. An exhaustive C search of every n up to 2·1010 found it: a prime p whose successor p + 1 = 2·3·5·7·11·13·17·19·29·37 carries ten primes, none dividing p. The same search reproduces all nine earlier terms.

A401531approved · Nov 2026

Floating-point reciprocals that don't round-trip

Count the n-bit significands X for which rounding X · round(1/X) does not give back exactly 1. It's the kind of edge case that floating-point hardware and math libraries have to get right. The direct count takes 2n steps. I found and proved a closed formula that turns it into lattice points under a hyperbola, counted with a convex-hull (Stern–Brocot) walk in O(22n/3). That took the table from n = 36 to n = 52. The formula is in the entry, signed with my name.

a(n) = N + S(K − H − 1) + S(K) − S(2K)        N = 2n−1, K = 22n−1, H = 2n−2
S(M) = ΣX=N..2N−1 ⌊M / X⌋

Common prime factors of binomial coefficients: the case i = 3 of a problem of Erdős and Szekeres

Erdős problem #699 asks whether C(n, i) and C(n, j) always share a prime factor greater than i. I verified the conjecture by computer for every n ≤ 109 (15.3 billion cases past 108, no counterexample), settled the case i = 3 for all n ≤ 1024, and proved an explicit lower bound on the shared factor via Dixon's identity. The problem itself is still open.
